# Security Policy

## Supported Versions

Security updates are provided for the latest public Pavo release. Older builds
may not receive fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Use GitHub's
[private vulnerability reporting](https://github.com/HZZZZ77/Pavo/security/advisories/new)
to share:

- A description of the issue and its potential impact
- Reproduction steps or a proof of concept
- Affected Pavo version and macOS version
- Any suggested mitigation, if known

Reports are reviewed on a best-effort basis. Please allow maintainers time to
investigate before publishing details. Never include private media files,
credentials, or unrelated personal data.
