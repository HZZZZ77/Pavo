# Pavo Support

Pavo is a community-maintained open-source project. Support is provided on a
best-effort basis through GitHub.

## Before Asking for Help

1. Check the [README](README.md) for installation and build requirements.
2. Review the current [Known Issues](docs/release/KNOWN_ISSUES.md).
3. Search existing [GitHub Issues](https://github.com/HZZZZ77/Pavo/issues).
4. Confirm that the problem occurs with the latest available Pavo release.

## Report a Bug

Use the
[bug report template](https://github.com/HZZZZ77/Pavo/issues/new/choose) and
include reproduction steps, your macOS version, Mac model, and relevant media
details.

Pavo logs are stored at `~/Library/Logs/Pavo/pavo.log`. Remove private file paths
and filenames before posting logs publicly. Do not upload copyrighted or private
media.

## Request a Feature

Use the
[feature request template](https://github.com/HZZZZ77/Pavo/issues/new/choose).
Please explain the user problem and the smallest useful solution. Requests are
evaluated against Pavo's local-first, playback-focused product direction.

## Security

Potential vulnerabilities must be reported privately according to the
[Security Policy](SECURITY.md), not through a public issue.

## Response Expectations

There is no guaranteed response time or private one-to-one support channel.
Clear, reproducible reports are the easiest for maintainers to investigate.
