# Pavo Product Guide

本文档定义 Pavo 的产品方向、目标用户和体验边界。它用于帮助维护者判断一个功能是否符合 Pavo，而不是描述具体实现方式。技术方案应遵循 `AGENTS.md` 和 `docs/DECISIONS.md`，版本计划应与 `docs/ROADMAP.md` 保持一致。

## Product Vision（产品愿景）

Pavo 希望成为一款真正愿意长期留在 macOS 用户电脑里的本地媒体播放器：打开迅速、播放可靠、界面克制，并且在需要时提供恰到好处的控制能力。

Pavo 不以功能数量定义价值。它的价值来自一条完整而可信的观看路径：用户打开一个或多个本地文件，立即开始播放，能够自然地暂停、定位、切换、选择字幕或音轨，并在完成观看后干净地回到空状态。应用不应让用户分心，也不应让用户为了理解播放器状态而反复确认。

长期来看，Pavo 应把 mpv 的成熟播放能力包装成符合 macOS 使用习惯的轻量桌面体验，在可靠性、审美和易用性之间保持平衡。

## Product Positioning（产品定位）

Pavo 是一款 macOS 优先、面向本地视频和音频文件的轻量播放器。

它位于系统自带播放器与复杂媒体中心之间：

- 比基础播放器提供更完整的格式支持、播放列表、缩略图预览、字幕、音轨、倍速和画面比例能力。
- 比大型媒体中心更轻、更直接，不要求建立媒体库、登录账号或配置复杂的插件系统。
- 比直接使用 mpv 命令行更易接近，为常用播放能力提供一致的图形界面和 macOS 交互。

Pavo 当前处于早期可用阶段。产品工作的首要方向是稳定核心播放体验、完善错误诊断和打包发布，而不是快速扩张功能边界。

## Current Product Baseline（当前产品基线）

Pavo 已经具备一款本地播放器的主要使用闭环：

- 通过 `Cmd+O`、File 菜单或拖放打开本地媒体。
- 支持一次选择多个文件并加入播放列表。
- 在没有当前媒体时自动播放第一个文件。
- 支持播放、暂停、快进、快退、进度定位、音量和静音。
- 支持播放列表排序、删除、清空以及播放结束后切换下一项。
- 支持 Recent Files，并自动忽略已经不存在的文件。
- 支持进度条缩略图预览。
- 支持全屏和 PiP。
- 支持字幕、音轨、倍速和画面比例选择。
- Clear Playlist 后能够停止播放并回到无当前媒体的空状态。

后续功能必须保护这条闭环，不能以新增能力为代价破坏已有播放行为或状态一致性。

## Target Users（目标用户）

### 主要用户

- 经常在 Mac 上播放下载视频、录屏、课程、演示或个人媒体文件的用户。
- 希望播放器足够简单，但需要比系统基础播放器更广格式支持和更多控制能力的用户。
- 需要快速浏览多个本地文件、使用播放列表连续观看的用户。
- 需要字幕、音轨、倍速、画面比例或缩略图定位能力的用户。
- 重视本地数据、隐私和低干扰体验，不希望使用账号或云端媒体库的用户。

### 次要用户

- 需要快速检查导出视频、录制结果或素材文件的创作者与开发者。
- 希望通过一个小型开源项目学习 Python、PySide6、mpv 集成和 AI 辅助开发的贡献者。

Pavo 不应为了满足少数高度专业的媒体管理或后期制作需求，让主要用户面对复杂的配置和操作成本。

## Core Principles（核心设计原则）

### Playback First

播放始终是第一优先级。打开文件、开始播放、切换媒体和恢复控制必须直接可靠。任何新功能都不应削弱核心播放路径。

### Quiet by Default

界面应在用户观看内容时退到背景中。HUD、播放列表、OSD 和提示只在需要时出现，不用持续动画、营销信息或装饰元素争夺注意力。

### State Must Be Truthful

播放按钮、进度、当前索引、缩略图、视频画面和菜单状态必须反映播放器的真实状态。暂停不能显示为播放，清空播放列表后不能残留最后一帧，切换媒体后不能出现旧媒体缩略图。

### Local and Private

本地媒体播放不需要账号、云同步或网络服务。播放历史、Recent Files 和设置应保存在本机，并尽量减少不必要的数据记录。

### Native macOS Habits

优先遵循 macOS 用户熟悉的窗口、菜单、快捷键、文件选择和 PiP 习惯。视觉上追求精致和通透，但不能让装饰影响可读性、性能或稳定性。

### Useful Complexity Only

只有能明显改善观看流程的功能才值得增加。复杂能力应按需出现，不应让默认界面承担所有高级选项。

### Reliability Before Expansion

稳定播放、明确错误、可诊断日志、可靠打包和基础回归检查，优先于新功能数量。一个可预测的播放器比一个功能丰富但状态不稳定的播放器更有价值。

### Progressive Maintainability

产品可以从小型项目持续成长，但每次演进都应保持已有功能稳定。架构拆分应由真实维护成本驱动，并通过 Task、Acceptance Criteria 和测试控制风险。

## What Pavo Is（Pavo 应该是什么）

Pavo 应该是：

- 一款打开即用的本地媒体播放器。
- 一款以 macOS 为主要体验目标的桌面应用。
- 一款由 mpv 提供可靠格式兼容和播放能力的图形播放器。
- 一款能够处理单文件观看和轻量播放队列的工具。
- 一款让常用功能容易找到、让高级功能不过度打扰的应用。
- 一款对异常有清晰反馈、对维护者有足够诊断信息的软件。
- 一款尊重本地文件、用户隐私和系统资源的开源工具。
- 一款适合长期迭代，而不是依赖一次性原型代码维持的产品。

## What Pavo Is Not（Pavo 不应该是什么）

Pavo 不应该是：

- 流媒体平台、在线视频搜索器或内容聚合服务。
- 需要账号、订阅、广告或推荐算法才能使用的产品。
- 以海报墙、元数据刮削和大型媒体库为核心的家庭媒体中心。
- 视频剪辑、转码、录屏或专业后期制作工具。
- 暴露大量 mpv 参数、要求普通用户理解底层播放配置的控制面板。
- 为展示毛玻璃效果而牺牲播放性能、对比度或操作清晰度的视觉实验。
- 为追求跨平台一致而削弱 macOS 体验的通用壳应用。
- 未经明确产品决策就加入遥测、远程日志或云端数据同步的应用。
- 把所有潜在功能堆入主窗口和 HUD 的复杂播放器。

## User Experience Goals（用户体验目标）

### 快速进入播放

用户通过文件选择器、Recent Files 或拖放打开媒体后，应尽快看到内容开始播放。多文件打开时，播放列表的建立和首项播放应自然衔接。

### 控制与状态一致

播放/暂停按钮、当前播放项、进度条、音量和窗口模式应始终与引擎状态同步。媒体结束、删除当前项、切换文件和 Clear Playlist 都必须得到明确且一致的状态结果。

### 浏览长视频高效

进度定位和缩略图预览应帮助用户快速找到内容，同时避免重复抽帧、旧图残留或过量 FFmpeg 进程影响播放。

### 多文件观看顺畅

播放列表应支持清晰的当前项、稳定排序、删除和连续播放。列表操作不能导致索引错乱、意外停止或播放错误文件。

### 高级能力按需出现

字幕、音轨、倍速、画面比例、PiP 和全屏应易于访问，但不应让默认观看界面显得拥挤。

### 空状态完整

没有当前媒体时，视频画面、进度、缩略图、播放状态和索引必须一起重置。空状态不是临时残留状态，而是产品中的正式状态。

### 错误可理解

文件不存在、格式无法播放、mpv 初始化失败或 FFmpeg 缺失时，用户应得到简短、可行动的提示。维护者应能通过日志进一步定位原因，但日志不能代替必要的用户反馈。

### 视觉克制且一致

Pavo 应保持当前简洁、半透明、偏 macOS 的视觉语言。新界面应优先保证层级、可读性、命中区域和状态反馈，而不是增加装饰。

## Product Decision Filter（产品决策判断）

评估新功能时，应依次回答：

1. 它是否明显改善本地媒体的打开、观看、定位、切换或管理？
2. 它是否服务于主要用户，而不是只满足少数复杂场景？
3. 它能否在不破坏现有播放状态和 UI 一致性的前提下实现？
4. 它是否符合 macOS 优先、本地优先和低干扰原则？
5. 它带来的长期维护成本是否与用户价值相称？
6. 它是否应该现在进入产品，还是应等待稳定性、测试和发布基础完善后再做？

如果一个提议无法通过这些问题，应缩小范围、推迟或明确拒绝。

## Long-term Vision（长期愿景）

### V1.1：可信赖

首先让 Pavo 成为稳定、可诊断的播放器。重点包括缩略图资源控制、统一日志、播放失败诊断、Clear Playlist 和连续播放回归、打包资源可靠性以及基础检查能力。

### V1.2：更自然

在稳定基础上改善日常体验，包括更完整的 File 菜单、偏好设置、空状态、文件类型处理和播放列表细节。新增功能应保持界面克制，并遵循 macOS 使用习惯。

### V2.0：可持续

当现有结构确实限制维护时，逐步拆分播放控制、播放列表、数据存储和缩略图服务，建立测试、质量工具和可重复的 macOS 发布流程。架构演进的目标是降低回归风险，而不是追求形式上的复杂度。

最终的 Pavo 应是一款体积轻、启动快、播放稳、界面安静的 macOS 本地播放器。用户不需要理解它背后的 mpv、FFmpeg、OpenGL 或 Python，只需要相信：把文件交给 Pavo，它就会正确播放。
