# Pavo 当前版本状态

Pavo 当前处于早期可用版本阶段：核心播放器体验已经成型，具备本地视频播放、播放列表、HUD 控制、进度预览、Recent Files、Clear Playlist、PiP、全屏、字幕和音轨选择等能力。

当前代码仍以快速迭代形态为主，主要逻辑集中在 `src/main.py`。下一阶段应优先提高稳定性、错误可见性、打包可靠性和回归测试能力，再考虑更大的架构演进。

# V1.0 已完成能力

## 本地媒体播放

- 目标：支持打开本地视频或音频文件并播放。
- 原因：这是 Pavo 的核心产品能力。
- 涉及文件：`src/main.py`、`src/engine.py`、`src/video_widget.py`
- 风险：mpv 初始化失败、文件路径失效或播放格式异常时，需要保证用户能看到明确提示。

## HUD 播放控制

- 目标：提供播放/暂停、快进/快退、进度条、音量、静音、全屏、PiP、字幕、设置等控制入口。
- 原因：HUD 是 Pavo 当前最重要的交互表面。
- 涉及文件：`src/components/hud_panel.py`、`src/main.py`
- 风险：HUD 状态如果与 mpv 真实状态不同步，会出现按钮图标错误或误操作。

## 播放列表

- 目标：支持多文件加入、双击播放、拖拽排序、右键删除和自动播放下一项。
- 原因：播放列表决定连续观看体验。
- 涉及文件：`src/main.py`
- 风险：删除当前播放项、排序后索引变化、清空播放列表时容易产生状态错乱。

## Open File 和拖放打开

- 目标：支持 `Cmd+O`、`File > Open File...` 和拖放文件。
- 原因：这是桌面播放器最基础的文件入口。
- 涉及文件：`src/main.py`、`src/video_widget.py`
- 风险：文件类型过滤不足时，非媒体文件可能被加入播放列表并触发播放失败。

## Recent Files

- 目标：记录最近打开文件，最多保留 20 条，重复项移动到最前，文件不存在时忽略。
- 原因：提升重复打开常用文件的效率。
- 涉及文件：`src/main.py`
- 风险：最近文件、播放列表和数据保存之间需要保持一致，避免无效路径长期残留。

## Clear Playlist

- 目标：清空播放列表、停止播放、重置当前索引，并让播放器回到空状态。
- 原因：用户需要快速清理播放队列，且不应残留最后一帧或缩略图预览。
- 涉及文件：`src/main.py`、`src/engine.py`、`src/video_widget.py`、`src/components/hud_panel.py`
- 风险：如果只清列表不清引擎状态，容易留下最后一帧、旧缩略图或错误的当前媒体状态。

## 缩略图预览

- 目标：鼠标悬停进度条时通过 FFmpeg 抽帧显示预览图。
- 原因：提升长视频定位体验。
- 涉及文件：`src/main.py`、`src/engine.py`、`src/components/hud_panel.py`
- 风险：快速移动进度条可能产生大量 FFmpeg 子进程；缓存无上限可能增加内存占用。

## 字幕、音轨、倍速和画面比例

- 目标：支持外部字幕、内置字幕轨、音轨选择、倍速和画面比例切换。
- 原因：满足基本播放器设置需求。
- 涉及文件：`src/main.py`、`src/engine.py`
- 风险：mpv 属性读取失败时目前错误可见性有限，后续需要增强诊断能力。

# V1.1 稳定性优化计划

## 限制缩略图抽帧并发

- 目标：为缩略图请求增加任务节流、取消过期请求或单 worker 队列。
- 原因：当前每次请求会启动线程和 FFmpeg 子进程，快速悬停可能造成资源压力。
- 涉及文件：`src/engine.py`、`src/main.py`
- 风险：如果取消逻辑处理不当，可能导致缩略图延迟、错图或悬停体验变差。

## 增强错误提示和日志

- 目标：让 mpv 初始化失败、播放失败、字幕加载失败、FFmpeg 缺失、数据保存失败都有可见提示或日志。
- 原因：目前仍有多处异常被静默吞掉，维护和用户排查都困难。
- 涉及文件：`src/engine.py`、`src/main.py`、`src/bootstrap.py`
- 风险：过多弹窗或 OSD 可能干扰播放体验，需要控制提示频率。

## 修复打包资源配置

- 目标：确认 PyInstaller 打包时包含必要的 icon、ffmpeg、mpv 相关依赖和运行环境配置。
- 原因：代码已经考虑 `_MEIPASS` 路径，但 `Pavo.spec` 当前没有明确声明资源。
- 涉及文件：`Pavo.spec`、`src/engine.py`、`src/bootstrap.py`
- 风险：macOS 不同架构和 Homebrew 安装路径会影响打包后的可运行性。

## 建立基础回归检查

- 目标：为播放列表、Recent Files、数据保存、路径过滤等低层逻辑建立最小测试或检查脚本。
- 原因：当前功能迭代依赖手动测试，容易出现状态回归。
- 涉及文件：`src/main.py`，未来可新增测试目录
- 风险：现有逻辑耦合 UI，直接单元测试成本较高，可能需要先抽出纯逻辑函数。

## 清理仓库体积风险

- 目标：确认 `venv/`、`build/`、`dist/`、本地二进制资源的版本管理策略。
- 原因：当前本地项目体积较大，不利于开源协作和长期维护。
- 涉及文件：`.gitignore`、`Pavo.spec`、`ffmpeg`
- 风险：如果直接移除二进制但没有替代安装或打包策略，会影响用户运行。

# V1.2 用户体验优化计划

## 完善 File 菜单

- 目标：增加清空 Recent Files、移除失效文件、显示文件位置等桌面常见操作。
- 原因：Recent Files 和播放列表已经存在，下一步应补齐管理入口。
- 涉及文件：`src/main.py`
- 风险：菜单项过多会让简单播放器显得复杂，需要保持克制。

## 增加基础偏好设置

- 目标：支持默认音量、是否恢复播放进度、默认字幕行为、窗口尺寸记忆等设置。
- 原因：这些是播放器日常使用中高频影响体验的选项。
- 涉及文件：`src/main.py`，未来可新增设置存储模块
- 风险：继续把设置逻辑写入 `main.py` 会加重主窗口复杂度。

## 优化空状态

- 目标：无媒体时统一按钮、进度条、OSD、缩略图、播放列表状态。
- 原因：空状态是播放类应用很容易出现残留 UI 的地方。
- 涉及文件：`src/main.py`、`src/video_widget.py`、`src/components/hud_panel.py`
- 风险：空状态处理如果过度，会误影响暂停、播放结束和切换文件场景。

## 改善文件类型处理

- 目标：更清晰地区分视频、音频、字幕和未知文件。
- 原因：当前除字幕外的文件容易被当成媒体加入播放列表。
- 涉及文件：`src/main.py`
- 风险：过滤过严可能让 mpv 实际可播放的格式无法打开。

## 改善播放列表体验

- 目标：支持清晰的当前播放标识、批量删除、清空、失效文件提示和更友好的长路径展示。
- 原因：播放列表是当前功能较完整但仍可打磨的区域。
- 涉及文件：`src/main.py`
- 风险：UI 改动需要保持现有玻璃风格，不应引入突兀的视觉语言。

# V2.0 架构演进计划

## 拆分播放控制器

- 目标：将播放状态、自动下一项、恢复进度、停止和错误处理从 `src/main.py` 中拆出。
- 原因：当前主窗口承担过多业务逻辑，长期维护成本会继续上升。
- 涉及文件：`src/main.py`、`src/engine.py`，未来可新增 `src/playback_controller.py`
- 风险：拆分播放状态容易引入按钮状态、自动播放和进度恢复回归。

## 拆分播放列表模型

- 目标：将播放列表、当前索引、排序、删除、清空、持久化协调拆成独立模型。
- 原因：播放列表是状态密集区域，应该降低 UI 和数据的耦合。
- 涉及文件：`src/main.py`，未来可新增 `src/playlist_model.py`
- 风险：模型和 QListWidget 同步如果处理不好，会导致选中项和实际播放项不一致。

## 拆分 Recent Files 和数据存储

- 目标：将 `~/.pavo_data.json` 的读写、schema version、异常恢复和最近文件逻辑独立出来。
- 原因：数据格式会随功能增长变复杂，需要可迁移、可测试。
- 涉及文件：`src/main.py`，未来可新增 `src/storage.py`
- 风险：迁移旧数据时必须兼容已有用户的 `playlist`、`history`、`recent_files`。

## 独立 ThumbnailService

- 目标：把 FFmpeg 查找、抽帧队列、缓存、取消过期请求从引擎中拆出。
- 原因：缩略图不是 mpv 播放控制的核心职责，且需要更强资源管理。
- 涉及文件：`src/engine.py`、`src/main.py`，未来可新增 `src/thumbnail_service.py`
- 风险：异步信号和媒体切换时机复杂，容易出现旧视频缩略图污染新视频。

## 建立发布工程

- 目标：建立可重复的 macOS 打包、签名、公证和发布流程。
- 原因：Pavo 的长期目标是桌面应用，发布可靠性和安装体验非常关键。
- 涉及文件：`Pavo.spec`、`requirements.txt`、`src/bootstrap.py`、`ffmpeg`
- 风险：签名、公证、动态库路径、二进制架构都会影响最终用户启动体验。

## 引入质量工具

- 目标：引入格式化、lint、类型检查、单元测试和最小 CI。
- 原因：项目进入长期维护后，需要自动化保障避免功能回归。
- 涉及文件：`requirements.txt`，未来可新增配置文件和测试目录
- 风险：一次性引入过多工具会打断开发节奏，应分阶段落地。

# 当前最高优先级任务列表

## P0：验证并稳定 Clear Playlist 空状态

- 目标：确保 Clear Playlist 后视频画面黑屏、无最后一帧、无缩略图预览、无当前媒体状态。
- 原因：这是用户已经复现过的状态残留问题，影响基础可信度。
- 涉及文件：`src/main.py`、`src/engine.py`、`src/video_widget.py`、`src/components/hud_panel.py`
- 风险：停止 mpv 和清空 OpenGL 画布的时序可能影响后续重新打开视频。

## P0：验证播放结束自动下一项

- 目标：确保播放结束后跳转到下一文件并自动播放，按钮状态正确。
- 原因：连续播放是播放列表的核心价值。
- 涉及文件：`src/main.py`、`src/engine.py`、`src/components/hud_panel.py`
- 风险：mpv 的 `pause`、`eof-reached` 和新文件加载事件顺序可能导致状态不同步。

## P1：限制缩略图抽帧资源占用

- 目标：避免快速悬停进度条时创建过多线程和 FFmpeg 子进程。
- 原因：这是当前最明显的性能和稳定性隐患。
- 涉及文件：`src/engine.py`、`src/main.py`
- 风险：队列和取消逻辑需要保持缩略图响应速度。

## P1：补齐播放失败诊断

- 目标：为播放失败、路径不存在、mpv 初始化失败、FFmpeg 缺失提供一致的提示和日志。
- 原因：播放器遇到环境问题时必须可诊断。
- 涉及文件：`src/engine.py`、`src/main.py`、`src/bootstrap.py`
- 风险：错误提示如果过于频繁，会干扰正常播放。

## P1：修正 PyInstaller 打包资源

- 目标：让打包后的 `.app` 能可靠找到 ffmpeg、图标和必要运行依赖。
- 原因：当前代码和 `Pavo.spec` 对资源打包的假设不完全一致。
- 涉及文件：`Pavo.spec`、`src/engine.py`、`src/bootstrap.py`
- 风险：本地开发环境可用不代表打包产物可用，需要真机验证。

## P2：整理数据保存边界

- 目标：让播放列表、播放历史和最近文件的读写逻辑更清晰，并兼容旧数据。
- 原因：当前数据逻辑集中在主窗口，后续扩展偏好设置会继续增加复杂度。
- 涉及文件：`src/main.py`，未来可新增 `src/storage.py`
- 风险：迁移数据格式时可能影响用户已有历史记录。

## P2：清理仓库和本地产物策略

- 目标：明确哪些产物进入仓库，哪些只保留在本地或发布包中。
- 原因：当前项目目录包含较大的 `venv/`、`dist/` 和 `ffmpeg`，会影响协作。
- 涉及文件：`.gitignore`、`Pavo.spec`、`ffmpeg`
- 风险：如果处理不当，可能导致新用户无法按 README 运行或打包。
